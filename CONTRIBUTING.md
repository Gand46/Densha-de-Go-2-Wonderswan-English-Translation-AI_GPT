# Contributing

Start with README.md and docs/CONTINUING.md. Follow docs/TRANSLATION_RULES.md.

For every change, record the original Japanese, natural English, resource offset, context, capacity, shared consumers and access method. Keep translated, integrated, runtime-confirmed, linguistically approved and visually approved as separate states. Preserve meaning, numbers and gameplay conditions; use NEEDS_CONTEXT/NEEDS_REVIEW when uncertain.

Include a reproducible build hash and before/after evidence. Do not submit ROMs, memory dumps, emulator saves, caches or local tool binaries to the public repository. Generated outputs belong in ignored directories.

Run the test-release build before edits. Use DEV outputs while working. Verify the affected consumer and neighboring graphics after each confirmed correction. Existing known-issue records must remain visible until evidence closes them.
